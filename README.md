# JobHub - Full-Stack Job Portal

A modern full-stack job portal that connects job seekers with employers. Job seekers can browse jobs, upload resumes, apply for positions, and track their applications, while employers can post jobs, review applicants, and manage application statuses.

## 🚀 Features

### 👤 Job Seekers

- Create an account
- Secure login
- Browse available jobs
- View job information
- Upload a CV/resume
- Apply for jobs
- Track application status
- Responsive dashboard

### 🏢 Employers

- Employer authentication
- Post job opportunities
- View company job listings
- Review applicants
- View candidate information
- Manage application statuses
- Employer dashboard

### 📊 Application Tracking

Applications can be managed through different stages:

- Applied
- Under Review
- Shortlisted
- Interview
- Rejected
- Hired
